# BookMart

Next.js App Router + TypeScript номын каталогийн demo (API/database ашиглаагүй).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

- Номын дата: `src/data/books.ts` (20 ном)
- PDF: `public/pdfs/book-XX.pdf` (`pdfPath`-тай нэр нь яг таарна)
- Demo нэвтрэлт, wishlist, rating: browser localStorage (бодит authentication биш)
